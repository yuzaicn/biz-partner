# 方法论与实践流程

方法把若干知识原子组合成可执行流程。步骤、门槛和停止条件都要结合当前客户、成本、风险与授权调整，不能替代现实证据。

## M-001 客户先行的短周期验证

在扩大产品投入前，为目标客户愿意为明确结果付费收集可观察证据。

**适用时机：** 只有模糊想法；现有产品没有稳定付费信号。

**输入：** 具体客户与任务；替代方案；问题证据；窄方案；可承受损失。

**步骤：**

1. 定义一个具体客户及其当前任务。
2. 记录客户已有替代方案和问题证据。
3. 提出范围清楚、可交付的窄方案。
4. 进行少量问题访谈并请求与风险相称的可观察承诺。
5. 按事前门槛决定继续、调整或停止。

**判断门槛：** 口头认可只算弱信号；没有可观察承诺时，付费意愿保持待验证。

**停止条件：** 无法触达目标客户；试验成本超过事前上限；问题证据持续不足。

**输出：** 客户任务记录；问题证据；窄方案；继续或停止决定。

**质量检查：** 客户和任务足够具体；访谈不诱导购买答案；承诺与风险相称。

**常见陷阱：** 先做完整产品；只问会不会买；把点赞当成交。

**关联原子：** `ka_maintainer_post_001`、`ka_maintainer_post_004`、`ka_curated_031`、`ka_curated_032`。

**关联概念：** `oc_001`、`oc_010`、`oc_019`、`oc_020`、`oc_027`、`bc_001`、`bc_031`。

## M-003 事实—推断—传播安全检查

让商业内容保留具体事实，同时不越过证据、隐私和外部发布边界。

**适用时机：** 准备新内容；复用旧材料；检查文稿可信度。

**输入：** 当前事实锚点；候选判断；发布场景；授权范围。

**步骤：**

1. 提取当前输入能够直接确认的事实。
2. 把推断与事实分开记录。
3. 删除没有事实支撑的具体细节。
4. 保留一个主要判断并检查隐私、广告、导流和平台边界。
5. 只输出草稿，外部发布前另行确认最终正文与目标范围。

**判断门槛：** 没有当前事实时先补事实；平台或授权边界不清时转人工复核。

**停止条件：** 关键事实无法核实；缺少发布授权；内容涉及无法安全处理的个人信息。

**输出：** 事实与推断清单；内容草稿；待确认发布信息。

**质量检查：** 每个具体细节可回指事实；推断有明确边界；发布动作未被草稿授权替代。

**常见陷阱：** 补造经历；把审核检查说成平台保证；用真实感掩盖证据缺口。

**关联原子：** `ka_maintainer_001`、`ka_maintainer_002`、`ka_maintainer_003`、`ka_maintainer_004`、`ka_curated_042`。

**关联概念：** `oc_005`、`oc_009`、`bc_008`、`bc_040`。

**状态：** 可发布

## M-004 行动—反馈—复盘回路

把拖延或泛学习转成能产生结果证据的最小实验。

**适用时机：** 知道方向但迟迟不行动；持续收集信息却没有结果。

**输入：** 目标结果；当前约束；可承受成本；复盘时间。

**步骤：**

1. 定义一次可验收动作。
2. 记录开始条件、预计成本和停止条件。
3. 在短周期内执行并保存结果。
4. 比较事前判断、实际结果和偏差。
5. 根据新事实调整下一步。

**判断门槛：** 动作必须能判断完成与否；没有结果证据时不升级长期结论。

**停止条件：** 成本或风险达到上限；动作无法产生信息；出现需要专业支持的状态信号。

**输出：** 最小行动；结果记录；偏差说明；下一次实验。

**质量检查：** 一次只改变少量变量；完成标准事前明确；复盘使用真实结果。

**常见陷阱：** 把笔记量当进步；事后改验收标准；没有停止条件。

**关联原子：** `ka_curated_005`、`ka_maintainer_post_004`、`ka_maintainer_post_005`、`ka_curated_028`、`ka_curated_043`。

**关联概念：** `oc_007`、`oc_008`、`oc_023`、`bc_016`、`bc_017`、`bc_028`、`bc_045`。

## M-005 方案价值而非接口价格

诊断技术服务是否解决客户交付问题，而不只比较底层资源单价。

**适用时机：** 产品被当成低价接口；客户从工具需求转向结果交付。

**输入：** 客户任务；服务责任；交付边界；单位经济；价格反馈。

**步骤：**

1. 把客户结果、服务方案、产品和底层资源分层描述。
2. 列出稳定性、支持和异常处理等真实责任。
3. 按当前台账核算单位经济。
4. 提出可验收的差异化承诺。
5. 用客户选择和价格实验验证。

**判断门槛：** 差异化不能只有更便宜；承诺必须有能力证据和责任边界。

**停止条件：** 单位经济持续为负且无改善假设；承诺超出现有能力；价格实验没有客户证据。

**输出：** 价值分层；责任清单；单位经济；价格假设。

**质量检查：** 成本口径完整；价值连接客户任务；异常责任可执行。

**常见陷阱：** 把功能数量当全部价值；用折扣代替定位；忽略支持和失败成本。

**关联原子：** `ka_maintainer_post_002`、`ka_maintainer_post_003`、`ka_curated_008`、`ka_curated_009`、`ka_curated_034`、`ka_curated_044`。

## M-006 数字商业的供给—触达—付费检查

判断供给增长、客户发现和收费理由是否真正衔接。

**适用时机：** 目录快速扩张；底层功能趋同；团队把供给数量当增长。

**输入：** 供给数据；触达与搜索数据；角色成本链；收费理由；单位经济。

**步骤：**

1. 确认供给能否稳定产生。
2. 验证目标客户能否触达、比较并找到合适选择。
3. 分开使用者、付费者、受益者和成本承担者。
4. 定位客户愿意付费的结果或责任。
5. 选择一个收费假设做小实验。

**判断门槛：** 触达、发现、成本或付费理由任一缺证据时保持假设；免费层没有收费价值时不扩大。

**停止条件：** 新增供给只增加噪声；履约成本吞噬尾部收入；免费增长扩大不可承受成本。

**输出：** 供给发现链；角色成本图；收费假设；验证指标。

**质量检查：** 目录不等于需求；尾部单独核算；非现金贡献有回报和治理边界。

**常见陷阱：** 把低边际成本当零总成本；先宣布抽象稀缺；无偿占用贡献。

**关联原子：** `ka_curated_006`、`ka_curated_007`、`ka_curated_008`、`ka_curated_009`、`ka_curated_033`、`ka_curated_037`、`ka_curated_038`。

## M-007 接收者验证的沟通回路

以接收者能否正确理解并继续协作为沟通验收。

**适用时机：** 客户访谈；需求澄清；团队分歧；棘手谈话。

**输入：** 共同目标；事实与解释；参与者语境；反馈渠道。

**步骤：**

1. 说明共同目标和当前范围。
2. 分开事实、解释和未知项。
3. 删除与任务无关的信息。
4. 用复述、开放提问、示例或行动反馈检查理解。
5. 升级时先修复轮次和合作条件。

**判断门槛：** 没有共享理解证据时，承诺和分工保持待确认；安全或权力风险出现时升级处理。

**停止条件：** 互动条件持续恶化；参与者无法安全表达；讨论离开当前授权范围。

**输出：** 共同理解；分歧与未知项；下一步协议。

**质量检查：** 接收者能复述关键点；语境和权力被考虑；理解不等于强迫同意。

**常见陷阱：** 不断增加信息；把发送完成当理解；用语气争执掩盖证据。

**关联原子：** `ka_curated_010`、`ka_curated_011`、`ka_curated_012`、`ka_curated_045`、`ka_curated_046`、`ka_curated_047`。

**关联概念：** `oc_014`、`oc_015`、`oc_017`、`bc_007`、`bc_008`、`bc_009`、`bc_047`、`bc_048`、`bc_049`。

## M-008 跨市场结构迁移检查

从外部案例迁移机制，同时避免照搬表面模板。

**适用时机：** 进入新地区或人群；迁移平台做法；引用外部成功案例。

**输入：** 当地规则；参与者角色；激励与行为；执行环境；退出条件。

**步骤：**

1. 分开当前资料中的事实、解释和假设。
2. 核对正式规则、现实执行和历史条件。
3. 比较参与者角色、行为与可能激励。
4. 改变系统边界和评价维度，生成结构差异假设。
5. 用小试点和退出条件验证迁移。

**判断门槛：** 关键规则或激励不清时只输出迁移假设；不可逆投入前必须有退出条件。

**停止条件：** 安全、许可或责任无法核实；试点结果否定核心机制；资金暴露达到上限。

**输出：** 结构对照；迁移假设；试点计划；退出方案。

**质量检查：** 不把文化标签当因果；不同证据不被平均化；异常样本被保留。

**常见陷阱：** 只看结果不看约束；把第一种类比当答案；从案例推广群体本质。

**关联原子：** `ka_curated_013`、`ka_curated_014`、`ka_curated_015`、`ka_curated_024`、`ka_curated_025`、`ka_curated_027`、`ka_curated_029`、`ka_curated_049`。

## M-009 共享意图到组织执行

把口头理解一致转成共同目标、共同注意、角色协议和可观察的交付验收行为。

**适用时机：** 团队项目；多人协作；会上理解一致但交付不一致；价值原则落地；组织叙事迭代。

**输入：** 共同目标；角色与注意对象；交付物；验收行为；价值词；行为证据；反馈范围。

**步骤：**

1. 分别复述并确认共同目标、关注对象、角色、交付物和验收行为。
2. 把口头对齐视为待验证协作假设。
3. 将价值词映射到已有证据支持的选择、行为和指标。
4. 形成边界清楚的叙事草稿。
5. 根据授权范围内的反馈提出行动更新。

**判断门槛：** 共享理解不足时先做对齐实验；价值词不能映射行为时不宣布落地。

**停止条件：** 角色授权不清；组织口号替代真实交付；外部发布未确认。

**输出：** 共同目标；共同注意；角色协议；验收行为；行为映射；叙事草稿。

**质量检查：** 目标可复述；口头点头不算执行一致；角色不等于目标；交付验收可观察；指标连接客户体验。

**常见陷阱：** 把口号当原则；把分工当对齐；用故事代替制度。

**关联原子：** `ka_curated_016`、`ka_curated_017`、`ka_curated_018`、`ka_curated_022`、`ka_curated_023`、`ka_curated_036`。

## M-010 关键约束与最小行动诊断

把抽象困扰整理成可解释、可观察、可复盘的非临床行动候选。

**适用时机：** 目标模糊；拖延或贪快；持续学习没有产出；高代价判断受直觉驱动。

**输入：** 目标结果；候选约束；证据与反例；可承受成本。

**步骤：**

1. 明确想改变的结果。
2. 选择少数最可能限制结果的因素。
3. 记录证据、反例和替代解释。
4. 设计一次最小可验收行动并约定复盘点。
5. 用结果更新约束判断。

**判断门槛：** 约束不能说明时保持候选；没有可观察行动时不宣布诊断完成。

**停止条件：** 出现临床或医疗信号；状态恶化；行动风险超过当前授权。

**输出：** 约束候选；最小行动；复盘点；更新后的判断。

**质量检查：** 不做人格分类；一次不改太多变量；结果反馈回判断。

**常见陷阱：** 把框架当诊断；把短期情绪当长期进步；只收集方法不行动。

**关联原子：** `ka_curated_019`、`ka_curated_020`、`ka_curated_021`、`ka_curated_025`、`ka_curated_026`、`ka_curated_027`、`ka_curated_030`、`ka_curated_043`。

## M-011 客户视角的一页方案

把客户问题、能力证据、交付步骤和行动入口整理成一页可验证方案。

**适用时机：** 首页或销售说明不清；复杂服务难以解释；多个渠道说法不一致。

**输入：** 客户任务；问题证据；能力证据；交付边界；行动入口。

**步骤：**

1. 用一句话写出具体客户和希望发生的变化。
2. 分开任务、挫败和价值判断，只保留有证据部分。
3. 用客户能够校正的表述确认处境，再放入相关能力证据。
4. 把外部流程压成少量步骤，并另列价格、时间和责任边界。
5. 设置主行动和有独立价值的过渡行动。
6. 写出可核实的不行动代价与成功结果。

**判断门槛：** 客户不能快速说明对象、问题、结果和下一步时继续修改；证据与承诺不匹配时降低承诺。

**停止条件：** 没有客户问题证据；方案超出现有能力；行动入口无法履约。

**输出：** 一页客户方案；主行动；过渡行动；待验证假设。

**质量检查：** 客户而非品牌是叙述中心；每项承诺有能力证据；复杂度没有被隐藏。

**常见陷阱：** 把框架当固定文案模板；补造客户感受；用简洁掩盖风险。

**关联原子：** `ka_curated_001`、`ka_curated_031`、`ka_curated_032`、`ka_curated_034`、`ka_curated_039`、`ka_curated_040`。

**关联概念：** `oc_010`、`oc_019`、`oc_021`、`oc_030`、`bc_001`、`bc_031`、`bc_032`、`bc_042`、`bc_043`。

## M-012 证据与因果审计

判断材料中的证据是否支持事实、比较或因果主张。

**适用时机：** 使用个案、专家或研究；引用增长率和平均值；把变化归因给单一原因。

**输入：** 待审计主张；来源；样本与测量；统计摘要；比较口径。

**步骤：**

1. 写出主张、理由和隐藏假设。
2. 区分启发线索与能够支撑主张的证据。
3. 检查样本代表性、测量方式、利益冲突、分母、基期和分布。
4. 列出竞争解释并核对时间顺序与共同原因。
5. 用证据边界重写结论强度。

**判断门槛：** 没有原始基数或测量说明时不作精确比较；替代原因未排除时只保留相关描述。

**停止条件：** 来源无法追溯；口径冲突无法校正；关键数据缺失且会改变结论。

**输出：** 论证结构；证据等级；因果限制；条件式结论。

**质量检查：** 每个主张有证据或明确假设；比例回到分母和基期；异常未被平均掉。

**常见陷阱：** 结论正确就接受错误论证；把相关当因果；用精确数字掩盖测量问题。

**关联原子：** `ka_curated_003`、`ka_curated_027`、`ka_curated_048`、`ka_curated_050`。

**关联概念：** `oc_005`、`oc_006`、`oc_025`、`oc_026`、`oc_028`、`oc_029`、`bc_019`、`bc_020`、`bc_021`、`bc_049`、`bc_050`。

**状态：** 可发布

## M-013 未知地图与问题发现

把不知道能做什么生意、没有明确方向等笼统未知，转成客户问题发现、异常检查和可安排的探索工作。

**适用时机：** 不知道自己能做什么生意；没有明确方向；既有指标无法解释异常；团队只会优化已知问题；方向选择缺少关键事实。

**输入：** 已知事实；可触达客户；现有替代；当前解释；异常样本；外部视角；待验证假设。

**步骤：**

1. 分开已知事实、解释和假设。
2. 方向不明确时先找可触达客户、现有替代和反复出现的问题证据，不从空白点子开始。
3. 标出已知、明确未知和尚未被命名的空白。
4. 把未知分为待验证、待定义和待持续观察。
5. 为每类未知安排外部观察、提问或小实验。
6. 从反复异常中重写问题定义。
7. 设定转入执行的证据门槛。

**判断门槛：** 没有事实、探索动作或验证标准时不把猜测写成结论；问题定义能被检验后才转入执行。

**停止条件：** 探索不再产生信息增量；问题不会改变当前决定；探索成本超过上限。

**输出：** 未知地图；异常清单；问题定义；探索任务；证据门槛。

**质量检查：** 未知项会改变决定；异常保留原始事实；每项探索有负责人和停止条件。

**常见陷阱：** 无限探索延误行动；过早把未知固化成解释；为完整而收集无关信息。
